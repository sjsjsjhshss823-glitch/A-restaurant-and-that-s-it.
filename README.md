# מלצר תלת־ממדי — משחק המסעדה

משחק מסעדה תלת־ממדי בדפדפן, בעברית, עם בחירת סוג מסעדה, דמות ורמת קושי.

## איך משחקים
1. פתחו את `index.html` בדפדפן עם חיבור לאינטרנט.
2. בחרו מסעדת המבורגרים, פיצרייה או סושי, דמות ורמת קושי.
3. התקרבו לדלפק המטבח ולחצו על כפתור הפעולה כדי לקחת אוכל.
4. גשו לשולחן של לקוח ולחצו שוב כדי להגיש.
5. השלימו את מספר המנות הנדרש וצברו נקודות.

## שליטה
- טלפון: כפתורי החצים וכפתור הפעולה שעל המסך.
- מחשב: WASD או מקשי החצים לתנועה; E או רווח כדי לקחת/להגיש.

## הפעלה
המשחק משתמש ב-Three.js דרך CDN, ולכן נדרש חיבור לאינטרנט כדי לטעון את ספריית התלת־ממד. אין צורך בהתקנה או במפתח API.

## פרסום דרך GitHub Pages
במאגר GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. לאחר השלמת הפריסה, האתר יהיה זמין בקישור GitHub Pages של המאגר.
