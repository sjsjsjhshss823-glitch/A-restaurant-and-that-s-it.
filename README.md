# מלצר המסעדה — משחק תלת־ממדי

משחק מסעדה תלת־ממדי בדפדפן, בעברית, עם בית קפה צבעוני בסגנון low-poly, לקוחות שיושבים בשולחנות, הזמנות אוכל, ניקוד, מטבעות ושלבים.

## איך משחקים
1. פתחו את `index.html` בדפדפן עם חיבור לאינטרנט.
2. בחרו תפריט (הכול מהכול, פיצרייה או המבורגרים), צבע מדים ורמת קושי.
3. גשו לדלפק המטבח וסחבו מנה באמצעות כפתור הפעולה.
4. מעל כל לקוח מופיעה המנה שהוא הזמין. גשו ללקוח המתאים והגישו אותה.
5. הגישו את מספר המנות הנדרש לפני שנגמר הזמן כדי לעבור שלב ולקבל מטבעות ונקודות.

## שליטה
- **טלפון:** כפתורי החצים שעל המסך וכפתור הפעולה.
- **מחשב:** WASD או מקשי החצים לתנועה; E או רווח לאיסוף ולהגשת אוכל.

## מה כלול
- סצנת תלת־ממד עם שולחנות, כיסאות, לקוחות, מטבח, צמחייה ותאורה.
- הזמנות של המבורגר, פיצה, סושי, סלט ושתייה.
- שעון, ניקוד, מטבעות, סבלנות לקוחות, שלבים ורמות קושי.
- ממשק בעברית המותאם למסכים קטנים.

## הפעלה
המשחק משתמש ב-Three.js דרך CDN, ולכן נדרש חיבור לאינטרנט כדי לטעון את ספריית התלת־ממד. אין צורך בהתקנה או במפתח API.

## פרסום דרך GitHub Pages
במאגר GitHub: **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**. לאחר השלמת הפריסה, האתר יהיה זמין בקישור GitHub Pages של המאגר.
